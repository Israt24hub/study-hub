    Admin sign-in

    Only the site owner can add or delete documents. Sign in with your GitHub access key for this repository.

    How do I get a key?
    1. Open GitHub → New fine-grained token.
    2. Name it Study Hub admin and pick an expiry (90 days is sensible).
    3. Repository access: Only select repositories → study-hub.
    4. Permissions → Repository permissions → Contents: Read and write.
    5. Generate it, copy it, and paste it here. Keep it secret, like a password.
